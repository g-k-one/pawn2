# Pawn — контекст проекта

Telegram Mini App с крафт-механикой: игрок ставит GRAM (бывш. TON) и/или NFT-подарки Telegram и получает provably-fair исход в одном из пяти рангов. Плюс кейсы, задания, достижения, супер дроп, рефералка, топ по XP.

**Состояние:** фронтенд готов как прототип. Сервера нет: seed, баланс, инвентарь, история считаются в браузере и сохраняются в localStorage (мок базы). Следующий этап — подключить настоящий бэкенд и перенести на этот фронт существующую БД. План и контракт — в `docs/BACKEND.md`. Арена и Ставки подробно — `docs/MODES.md`. Передача разработчику — `docs/HANDOFF.md`.

## Главные правила продукта (проверять каждое решение)
- **Консистентно** — одинаковые вещи выглядят и работают одинаково на всех экранах (GRAM, отступы, кнопки, тексты).
- **Просто** — меньше элементов, текста и шагов; лишнее убирать.
- **Понятно** — игрок без объяснений понимает, что произойдёт и сколько он получит.
- **Удобно** — частое действие в один тап, ничего не прыгает, ошибку легко исправить.
- **Интерактивно** — каждое действие даёт отклик: анимация, звук, вибрация.
- **Максимум саспенса** — раскрытие исхода держит в напряжении, но честно (без фейкового «почти выиграл»).
- **Чтоб захотелось вернуться** — у игрока всегда есть цель на сегодня и на потом.
- **Везде честно с проверкой** — любой исход в любом режиме проверяется доказательством `pawn-pf-v1`.

## Бизнес-правила
- Ранги и диапазоны тикета (0–99999), в коде — `TIERS` (`src/app/00-data.js`):
  | UI | key (сегмент) | zone | тикеты | шанс | множитель |
  |---|---|---|---|---|---|
  | База | base | base | 0–56562 | 56.563% | x0.4–x0.8 |
  | Удача | luck | luck | 56563–83562 | 27% | x0.8–x1.2 |
  | Мега | mega_low | mega | 83563–96552 | 12.99% | x1.5–x2 |
  | Ультра | mega_high | mega | 96553–99799 | 3.247% | x2–x3.5 |
  | Джекпот | jackpot | jackpot | 99800–99999 | 0.2% | x10–x14 |
- Множитель внутри сегмента — линейно по тикету, целочисленно в ppm (`craftPpm`), RTP 94.9996% (`RTP_PPM = 949996`). В UI показываем «RTP 95%».
- Валюта в UI — только **GRAM** (никаких «TON» в лейблах). Внутри суммы считаются в nano (1 GRAM = 1e9), в прототипе с точностью до сотых.
- Ставка: от 0.1 до 50 GRAM (`BET_MIN`, `BET_MAX`), NFT в ставке считаются по оценке. До 2 подарков в одном крафте (`MAX_GIFTS`).
- Выплата NFT: порог `NFT_FROM` = цена самого дешёвого подарка на релеере (считается из каталога, сейчас 3.5). Выигрыш от порога — самый дорогой NFT не дороже выигрыша, разница («сдача») — на баланс GRAM; меньше порога — GRAM. Флор обычного NFT в кейсах — тот же.
- Экран выигрыша: **Продать** — primary CTA, **Забрать** — secondary.
- Вывод — только NFT (вывода GRAM нет и не будет), **по одному**: каждый подарок — отдельный запрос, комиссия 0.3 GRAM (`OUT_FEE`), своё уведомление; сбой одного не трогает остальные. Перед выводом игрок должен написать релееру `@pawngift` (`RELAYER`). Депозит GRAM — только после подключения TON-кошелька (TON Connect), минимум 1 GRAM. Депозит NFT — передачей подарка релееру.
- XP: 0.5 за каждый поставленный GRAM + награды заданий/достижений/кейсов. Звания (`RANKS`, `09-xp.js`): 25 ступеней от «Нищуган» (0) до «ПАВНЕД» (22 000 XP) — список в коде. Топ по XP не сбрасывается.
- Кейсы (`CASES`, `10-cases.js`): Дуров 1 GRAM, Сатоши 2.5 GRAM — платные; Мистер Бист — бесплатный за 3 задания дня; Илон Маск — бесплатный за 7 дней заданий подряд. Бесплатные кейсы копятся (запас ×N), открываются по одному. NFT из кейса: редкий — случайный за 11–14 GRAM, обычный — по флору 3.5.
  | Кейс | Редкий NFT | Обычный NFT | GRAM | XP |
  |---|---|---|---|---|
  | Дуров (1 GRAM) | 1.48% | 5.69% | 1.5 — 13.6% · 0.7 — 27.2% · 0.3 — 33.4% | 25 — 18.63% |
  | Сатоши (2.5 GRAM) | 6.7% | 18.8% | 25 — 2.28% | 150 — 9.4% · 100 — 23.1% · 50 — 39.72% |
  | Мистер Бист | 0.05% | 0.95% | 0.75 — 8% · 0.25 — 14% · 0.1 — 26% · 0.05 — 28% | 100 — 4% · 50 — 9% · 25 — 10% |
  | Илон Маск | 1% | 8% | 2 — 13% · 1 — 24% · 0.5 — 24% · 0.3 — 19% | 750 — 2% · 300 — 4% · 150 — 5% |
  Сумма шансов каждого кейса — 100%; тикет → предмет по накопленным диапазонам (`CASES` → `from/to`).
- Задания дня (`TASKS`, `11-tasks.js`) обновляются в 00:00 МСК; пропущенный день недели восстанавливается за 0.5 GRAM.
- Достижения (`ACH`, `12-achievements.js`) — разовые, засчитываются по кнопке «Проверить» у каждого пункта: сервер проверяет условие только по нажатию (не нагружаем бэк фоновыми проверками).
- Супер дроп (`SUPER`, `13-super-drop.js`): кто первым выбьет загаданный тикет крафтом от 0.5 GRAM, забирает NFT.
- Рефералка (`REF`, `14-referrals.js`): 10% от первого депозита друга (до 0.5 GRAM) + 5% от активности друга ежедневно в 00:00 МСК.
- Демо-режим: бесконечные «фантики», кейсы и NFT недоступны, в историю и задания не идёт.
- PvP крафт — режим **Арена** в переключателе внизу (`16g-tab2.js`, внутри — `tab2`; отдельного таба PvP нет): копия главной — у tab2 свой выбранный ранг, тикет — колесом (свайп в любом месте экрана крутит колесо; ранги — только тапом, смена ранга = наименьший тикет ранга), вместо приза — арена (колизей, зрители, кольцо таймера, дым Горна, 5 мест соперников: 2 + 3), на кнопке — щит и меч (`assets/arena-shield.svg`, `sword.svg`), тап по ней/ставке — удар и вход (в кнопке — аватарка, в плашке — «Общий банк»), «Честность» — щит на месте подарков. Ядро комнаты, мок и бой — `16a-pvp.js`: 3 комнаты — на 0.5, 1 и 2 GRAM (`PVP_FEES`), переключаются стрелками по бокам плашки ставки (опрашивается только комната на экране; вошёл — стрелки скрыты, ты всегда в одной комнате; к бою все шторы закрываются), таймер 30 с стартует с первым входом; мест 6 (5 соперников + ты на кнопке), заняты все — войти нельзя; за 5 с до старта тикеты зафиксированы у всех и войти нельзя (кнопка и ставка тёмно-серые, в кнопке пульсирует замок); бой начался — тем, кто не в нём, сразу открывается следующая комната; быстрый крафт на арену не действует, в демо арена недоступна; бои — в истории, таб «Арена»; дальше по-старому (старый экран арены ниже — больше не открывается): экран — круглая арена (векторный колизей, кольца тают за краями; лёгкий туман и пыль — эффект Горна `arena` на своём холсте под интерфейсом): тикет — ручкой по кольцу рангов вокруг банка или вверх/вниз по цифре; вход — тап по любому свободному месту на трибунах; внизу ряд «Честность | тикет | кубик», после входа тикет можно сменить до 5 с до старта; по таймеру выпадает тикет, ближе всех крафтит на весь банк с этим тикетом (та же анимация крафта, с игроками), ничья — банк поровну, один в комнате — крафт твой. Старт боя — удар молота по наковальне (PvP будем переделывать). В демо недоступен. Контракт — `docs/BACKEND.md`.
- Ставки — всегда в переключателе режимов: таб «Ставки» (`16h-tab3.js`). Три колоды (Ранг · Тикет · Последняя цифра) — переключатель сверху и стрелки у плашки; в центре крупная карта с исходами-медальонами, соседние — рубашкой. Фишки 0.1/0.5/1/5 внизу, тап по исходу кладёт фишку, долгое нажатие — снимает. Исходы: 5 рангов, чёт/нечет, до/от 50000, есть 7, пара, пары последней цифры (0–1…8–9); RTP 90% (ниже крафта, отдельная карточка «RTP ставок»), до 10 ставок, ставка до 50, выигрыш за раунд до 700 GRAM. Кнопка — хрустальный шар и палочка, фон — туманность. Итог — экран дропа крафта со строкой «ставка · сбылось K из M». Ядро — `16b-bets.js` (домен `bets`). Подробно — `docs/MODES.md`.
- Дебаг → «Арена и ставки»: исход боя (победа/проигрыш), сколько соперников в новой комнате, исход ставок — подбором настоящего зерна, проверка честности сходится.
- Кейсы и задания — в визуальном стиле текущего приложения.
- Бонусы — 3 вкладки по смыслу: **Сегодня** (задания дня, баннер супер дропа, неделя) · **Кейсы** · **Профиль** (таблетки Достижения | Друзья | Топ; выполненные достижения свёрнуты).
- **Сезон / «Пасс» (баттл пасс, прототип, `16k-season.js`)** — по умолчанию вместо бонусов: один экран **Пасс** без вкладок (тема сезона, уровень, карточка премиума → шторка подтверждения с выгодой, задания дня: 3 из набора + задание темы + 4-е для премиума, баннеры супер дропа и кейсов, дорожка 30 уровней: шкала по центру с XP, слева бесплатно, справа премиум; сундуки после 30-го). Друзья — из меню, топа нет. Оформление — 3 слота: рамка, значок у имени, эффект входа на Арену («Зелье» — Горн `potion`: жижа-метаболы и призраки; соперники видят твоё оформление — `entries[].eq`; в комнате 2 GRAM эффект у всех — `ENTRY_ROOM`). Очки — XP с начала сезона без XP из кейсов, 250 XP = уровень, 28 дней; премиум 10 GRAM: +20% XP, 4-е задание, сундуки, рамка. Сезон 1 — «Хэллоуин» (`SEASON_THEMES`). Конец сезона: незабранное выдаётся само. Старое звание — значком у имени, прежнему топу — разовые призы. «Как было» — `SEASON_ON` / `bm-season` (Дебаг → Сезон).

## Честность (обязательно)
- Provably fair: HMAC-SHA256, хеш server seed показывается ДО игры, проверка воспроизводима прямо в браузере.
- Протокол — `pawn-pf-v1`, эталон проверки: https://pawn-frontend.onrender.com/verify/fair-verify.js (копия — `tests/vendor/fair-verify.js`, тесты гоняют доказательства через неё). Доказательства из приложения должны проходить этот сайт.
- Ролл: ключ HMAC — 32 байта server seed, сообщение — компактный JSON `["pawn-pf-v1", epoch_id, domain, client_seed, nonce, block]`; восемь uint32 big-endian, первое < 4294900000 → mod 100000; не подошло — следующий блок. Домены: `craft`, `case:<id>`; nonce общий и растёт.
- Эпохи: seed загадан заранее (виден commitment = SHA-256 seed), игры идут с растущим nonce; seed раскрывается, когда игрок меняет свой ключ (client seed), и тут же загадывается новая эпоха.
- Под капотом сегменты: base, luck, mega_low, mega_high, jackpot (mega_low и mega_high — zone `mega`); в UI — Мега и Ультра.
- Анимации раскрытия честные: никаких фейковых «почти выиграл» (near-miss).
- Показывать RTP (целевой и личный — в «Статистике»).
- В бою server seed живёт ТОЛЬКО на сервере. В моке он в браузере и в localStorage — это допустимо только для прототипа.

## Производительность
- Цель: плавно на iPhone 11 и старых Xiaomi.
- Следить за бюджетом памяти WebGL; свечение рамки в покое — 12 fps, размер рамки постоянный (разрешение не снижать — рамка «шакалится») (`18-glow-start.js`), цикл не будит страницу каждый кадр экрана; lite-режим для слабых GPU (предлагается сам, если fps < 40; в нём без анимаций, без вращения NFT, лента «лайв» вдвое реже).
- Учитывать safe-area Telegram Mini App (`fit()` в `00-data.js`).
- iPhone в Telegram греется от постоянной работы, а не от разовых эффектов. Правила: никаких постоянных эффектов Горна на WebGL (дым арены — 8 копий одной картинки клуба `assets/arena-puff.webp`, плавают по случайным траекториям (`smokePuffs`, только transform/opacity)); анимировать только `transform` и `opacity` у HTML-элементов — не тени, не фильтры и не элементы внутри SVG (их телефон перерисовывает каждый кадр); то, что крутится пальцем (колесо арены), — отдельный слой. Холст Горна в простое убирается (`display:none`).
- Ещё по скорости (выяснено замерами): 3D-поворот и параллакс NFT выключены (`TILT_ON` в `03-tilt.js`); рамка в движении — не чаще 60 к/с; невидимое прятать совсем (`visibility`/`display`), а не прозрачностью — иначе держит слой; не анимировать то, что лежит под `mask-image` (мерцающие зрители Арены вынесены из-под маски); шрифт и уведомление прогреваются при запуске (`19-perf.js`); замер на телефоне — Дебаг → «Замер» (плашка FPS и выключатели).
- Переходы (по исследованию): View Transitions для смены режимов пробовали — на iPhone ломался порядок слоёв и низ прыгал, выключено (`VT_ON` в `16f-modes.js`), работает ручной переход; пружины (перелёт) тоже не понравились — `--spring` теперь ровная кривая; `content-visibility` откатили (колизей появлялся с задержкой). Колизей Арены запекается в картинку при запуске (`t2Bake`), режимы прогреваются (`modesWarm`), картинки меню, бонусов и кейсов предзагружаются сразу после лоадера (`19-perf.js`). Анимировать ширину/высоту по возможности не стоит — только transform и opacity.
- Картинки подарков: 128 px для мелких (лента, история), 256 px для карточек, 1024 px с cdn.changes.tg — только для крупного приза.

## Визуальные решения (приняты)
- Edge Glow фон на WebGL-шейдерах с настраиваемыми цветами.
- Мягкий блик вместо голографической фольги.
- Переходы — crossfade с глубиной, а не боковые слайды.
- Звуки (WebAudio, синтез) и haptics — да.
- Debug-панель для принудительного исхода (только QA): ранг/тикет, сбои, запас кейсов, имитация подключённого кошелька (пополнение без подписи), сброс прогресса.
- Плитки тикета при раскрытии — без обводки.
- Карточки Provably Fair: иконка/цифра в общей колонке 48 px, текст всех карточек — на одной линии.
- Меню → «Другое»: первым пунктом «Вывод NFT» (открывает вывод), чтобы его находили не только через баланс.
- GRAM: суммы синие (`var(--blue)`), иконка — плоский гем; в плашках и кнопках — гем + число, в тексте — «N GRAM». Гем рядом с числом — цвета числа; где число белое (плашка ставки, «Общий банк» на раскрытии) — белый плоский гем `assets/gem-white.svg`. В ленте «лайв» гема нет. Знаки «+/−» у сдачи и в итогах Арены не ставим — смысл несёт цвет (пришло — зелёный, проиграл — серый). Выигрыш/«пришло» — зелёный, «ушло» (GRAM) — белый, оранжевым GRAM не бывает. XP — всегда оранжевый со своей иконкой.
- Карточки и плашки: внутренний отступ 16 px со всех сторон, скругление 22 px. Экраны с крупным заголовком по центру (кейс, пополнение) — подзаголовки тоже по центру.
- Отступы: внутри группы 8 px, между группами 20 px. Мелкий текст — не меньше 12.5 px, длинный — 13.5 px, серый не тусклее .72.
- Тексты: задания и достижения — в повелительном наклонении («Сделай…»). У каждого невыполненного достижения — кнопка «Проверить» (проверка на сервере по нажатию). Раздел честности называется «Честность».
- Номер тикета везде — пять цифр без пробела (`tk()`), как на барабане.
- Корзина у ставки: первое нажатие убирает GRAM, следующее — подарки. Доказательство и подтверждение — «Скопировать» (в буфер).

## Устройство кода
- `src/index.html` — разметка; `src/styles.css`; `src/boot.js` — загрузчик (проверяет CDN, без него берёт запасные картинки `assets/g`); `src/app/*.js` — приложение, склеивается по порядку имён в одно замыкание (общие переменные видны во всех файлах); `src/data/relay.json` — каталог NFT релеера (`c` коллекции, `b` фоны, `g` подарки `[коллекция, номер, модель, фон, символ, цена, ключ картинки модели, ключ символа]`); `src/i18n/en.json` — английский.
- Модули: `00-data` (язык, ранги, правила PF, NFT, масштаб) · `01-tiers` (переключение рангов, превью приза) · `02-bet-drawers-menu` (ставка, шторки, инвентарь, меню) · `03-tilt` · `04-live` (лента) · `05-craft` (PF-ядро, дебаг, настройки, звук, уведомления, крафт, раскрытие, дроп) · `06-fairness-ui` · `07-history` · `08-wallet` (TON Connect, депозит, вывод) · `09-xp` · `10-cases` · `11-tasks` · `12-achievements` · `13-super-drop` · `14-referrals` · `15-top` · `16-bonuses` (экран бонусов, открытие кейсов, баланс, стартовая история-заглушка) · `16e-forge` (**Горн** — наш движок частиц на WebGL, `Forge.play(имя, { x, y, size, el, loop })`, 11 эффектов; атласы `assets/fx`, карта `16e-forge-atlas.js` — генерирует `design/rive/lab-fx/atlas.mjs`; проверка — Дебаг → «Эффекты частиц», покадровая съёмка — `node tools/fx-shots.mjs anvil,potion`; принципы и план — `docs/VFX.md`) · `16l-extrude` (**Объём** — псевдо-3D текст: копии стопкой в глубину, градиенты лица и боковин, свет по кромке, крутится пальцем с инерцией и пружиной; отделка лица — обводки, свечение к кромке и вокруг, курсив (поле расстояний до кромки); материал — фаска, купол и утолщение (bubble), металл-отражение, пробегающий блик `t.shine()`; буквы — отдельные ячейки атласа со своим движением, появления `t.play(drop | pop | slam | wave | out, { onLand })`; `Extrude.mount(el, { text, depth, face, side })`; рисует только в движении, копий — по углу, в lite — один кадр; лаборатория — `design/extrude/index.html`) · **`17-api`** · `18-glow-start` (шейдер, старт, онбординг).
- **`17-api.js` — единственная граница с «сервером»:** `API.craft`, `claimCraft`, `openCase`, `receipt`, `rotateSeed`, `withdrawNft`, `confirmDeposit`, `sellNfts`. Сейчас мок; при переносе меняется только этот файл (контракт — `docs/BACKEND.md`). Там же `track()` (аналитика) и `Store` (сохранение прогресса в localStorage `pawn-state-v1`).
- Состояние — объект `S` (баланс, ставка, история `S.hist`, XP, задания, запас кейсов, достижения, эпоха `S.ep`, nonce, client seed), инвентарь — `INV`.

## Как работать
- `index.html` в корне — собранный файл, руками не править. `npm install`, затем `npm run build` (минифицированно) или `npm run dev` (без минификации). `npm run serve` — локальный сервер на :8765.
- `npm test` — сквозные тесты в headless Chromium (`tests/app.test.mjs`): запуск, крафт + проверка доказательства эталоном, кейс, поштучный вывод, сохранение прогресса, английский без русского текста. `npm run check` — переводы + сборка + тесты. То же гоняет GitHub Actions (`.github/workflows/check.yml`), включая проверку, что `index.html` собран из текущих `src/`.
- `npm run dist` — папка `dist/` для хостинга (без 40 МБ `assets/g`, они нужны только просмотрщику artifact, где CDN закрыт).
- Локализация — шаблоны: в коде `$t("Русский текст {0}", arg)`, ключ — сам русский текст; множественное число — `$n("задание|задания|заданий", n)` (в en.json `"task|tasks"`). Английский — `src/i18n/en.json` (вшивается в сборку). Статика в `src/index.html` — атрибут `data-t` (и `aria-label`). Смена языка перезагружает страницу. `npm run i18n` показывает ключи без перевода — перед коммитом должно быть 0.
- Новый файл в `src/app/` — номер в имени задаёт порядок склейки.
- Правки — точечными диффами, не переписывать файлы целиком.
- Перед тем как сказать «работает» — проверить в headless Chromium (скриншоты, perf) и прогнать `npm test`.
- Деньги и исходы игр — только через `API` в `17-api.js`, не мимо него.
- Общение на русском, коротко. Заказчик — дизайнер, не разработчик: объяснять без жаргона.
