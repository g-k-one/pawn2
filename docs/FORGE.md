# Горн — движок эффектов

Горн (Forge) — эффекты частиц, ударов, щитов, стекла и искажений картинки на WebGL. Без зависимостей, один глобальный объект `Forge`.
Работает в любом веб-проекте: сайт, Telegram Mini App, игра на HTML. Рассчитан на телефоны (iPhone 11, старые Xiaomi): сам снижает качество,
если не успевает, в простое отдаёт память.

## Что в папке

| файл | что это |
|---|---|
| `forge.js` (`forge.min.js`) | ядро: движок и базовые эффекты `anvil` (искры удара), `potion` (зелье). Обязателен |
| `forge-classic.js` | огонь, взрывы, порталы, молнии, ауры, раскрытия, монеты, конфетти |
| `forge-particles.js` | поток-вихрь, воронка, салют, рассыпание картинки в пыль |
| `forge-image.js` | эффекты картинки: глитч, помехи, стекло, изморозь, волна, воронка, линза, марево, пиксели, желе, осколки |
| `forge-hits.js` | удары и щиты в стиле League of Legends (нужен `image`) |
| `forge-motion.js` | крит, мультяшный удар, щит из сот, кольцо-солнце, клякса, неоновая жижа, нарезка, раскрытие рангов (нужны `image`, `hits`) |
| `forge-glass.js` | стекло: жидкое, грани кристалла, лупа, дождь, протереть изморозь, призма |
| `forge-matter.js` | объёмные предметы, кувыркающиеся в 3D и сгорающие с края: перо, монета, лепесток, самоцвет, сердце, бумажка, клуб дыма, пепел. Золотой взрыв, сгорающие перья, дождь монет, сакура, самоцветы, сердечки, угли, пепел, золотая аура (нужен `hits`) |
| `forge-remaster.js` | старые эффекты `classic`, собранные заново: монеты, конфетти, заряд, дым, ударная волна, мерцание, дух, облако, магический круг, комбо, галактика, раскрытия, энергосфера (нужны `hits`, `matter`; подключать после `classic`) |
| `fx/` | картинки эффектов. Лежит рядом с `forge.js` — Горн находит её сам |
| `demo.html` | живой пример: все эффекты по кнопкам |

Подключайте только нужные пакеты. Ядро — около 70 КБ исходника (`forge.min.js` меньше), пакеты — от 10 до 105 КБ.

## Подключить

```html
<script src="forge/forge.js"></script>
<!-- пакеты — после ядра и в этом порядке -->
<script src="forge/forge-image.js"></script>
<script src="forge/forge-hits.js"></script>
```

Через сборщик (Vite, webpack): файлы — обычные скрипты, без `import`. Подключите их тегами `<script>` или импортом ради побочного эффекта
(`import './forge/forge.js'`), а папку `fx/` положите в публичные файлы и укажите путь: `Forge.base = '/forge/fx/';`.

## Запустить эффект

```js
// в точке экрана: x, y — центр, size — сторона квадрата эффекта в пикселях (эффект задуман в квадрате 360 единиц)
Forge.play('anvil', { x: 200, y: 300, size: 360 });

// на элементе: эффект следует за ним и обрезается по его краям
Forge.play('hitsigil', { el: document.querySelector('.card') });

// пресет — после двоеточия: готовые цвета и настройки
Forge.play('hitsigil:arcane', { el });
Forge.play('shield:frost', { el, loop: true });   // зацикленный — до stop()

// эффекты картинки рисуют картинку сами — настоящую на это время спрячьте
const h = Forge.play('shatter', { el, img: 'gift.png' });   // картинка с другого сайта — только с CORS
```

Что вернёт `play` (или `null`, если эффекта нет, нет WebGL или не хватает картинки):

```js
h.stop();          // плавно погасить
h.kill();          // убрать сразу
h.alive();         // ещё играет?
h.set('hitAt', 1.2);   // поменять состояние на ходу (щит: удар в точку по углу)
```

Своя монетка: эффекты с монетами (`goldboom`, `coinrain`, `goldaura`, `coins`) принимают `img` — лицо каждой монеты рисуется из этой картинки,
ребро остаётся металлическим: `Forge.play('goldboom', { el, img: 'token.png' })`. Монеты — псевдо-3D цилиндр: при повороте видно ребро с насечкой.

Несколько картинок: `skinswap` принимает массив — каждая картинка становится своим обликом, эффект мигает между ними и режет кадры пополам:
`Forge.play('skinswap', { el, img: ['a.png', 'b.png', 'c.png'], loop: true })`. До 8 картинок; они склеиваются в один лист 1024×512, поэтому эффект остаётся одной отрисовкой.

Опции `play`: `x`, `y`, `size`, `el`, `loop`, `img`, `box` (сторона картинки, 240), `hold` (разовый эффект замирает на последнем кадре до `stop()`),
`s` (поправки состояния: цвета, палитры) и свои у каждого эффекта (`power`, `dir: 'in' | 'out'`, `tier` и т. п.).

## Настройки

```js
Forge.lite = true;     // экономный режим: минимум частиц и пикселей, заранее ничего не готовит, отдаёт видеопамять
Forge.quality = 1;     // 0 эконом · 1 среднее · 2 полное (по умолчанию)
Forge.auto = false;    // не снижать качество само (по умолчанию снижает, если кадр медленнее ~40 к/с)
Forge.base = '/fx/';   // где лежат картинки, если не рядом с forge.js
Forge.preload('aura'); // подготовить заранее, чтобы первый эффект не ждал загрузки (атлас aura — у большинства эффектов)
Forge.destroy();       // освободить всё; следующий play соберёт заново
Forge.list();          // [{ name, presets, img, period }] — что подключено
Forge.info();          // строка для отладки: атласы, качество, частицы, видеокарта
```

## Свой эффект

Теми же инструментами, что встроенные эффекты:

```js
Forge.define('pulse', k => ({ atlas: 'aura', period: 1,
  init(s){}, update(s, dt){},
  render(s, c){ const t = s.cycle;
    k.sprite(c, 180, 180, 120 + 200 * t, 0, 1 - t, 1, c.at.map['sglow:W0'], 1, [1, .6, .2]); } }));
```

`k` — частицы (`spawn`, `step`, `draw`), спрайты (`sprite`), ленты (`band`, `arcBand`), отрезки (`seg`), кривые (`crv`, `easeOut`), формы пакета hits (`SHP`).
Свой набор эффектов — пакетом: `Forge.pack('имя', k => { k.DEF.эффект = { … }; })`.

## Ограничения

- Горн рисует на своём холсте поверх страницы и не видит, что под ним: размыть или исказить живой интерфейс нельзя — только то, что рисует сам (картинки, формы).
- Картинки с чужих сайтов — только с заголовками CORS, иначе эффект картинки молча пропускается.
- Нет WebGL — `play` возвращает `null`, страница работает без эффектов.
- Холст — один на страницу, поверх всего (`z-index: 9000`). Эффект под интерфейсом — свой экземпляр: `makeForge(элемент)` рисует внутри элемента.

## Откуда берётся

Исходники — в проекте Pawn: ядро `src/app/16e-forge.js` (+ карта атласов `16e-forge-atlas.js`), пакеты `src/forge/*.js`, картинки `assets/fx`.
