# Цезарь — заставка старта арены (Spine, WebGL)

Арт — нейросеть (Figma, gpt-image-2.5) по правилам `../ART-RULES.md`:
- `face-sheet.png` — лицо по частям: голова без бровей, глаз и рта; брови, глаза, веки, верхняя губа с зубами, челюсть, полость рта, венок (две половины);
- `parts-sheet.png` — торс и руки (голова и челюсть с этого листа не используются);
- `lightning-sheet.png` — 6 рисованных кадров молнии на чёрном;
- `colosseum.png` — фон, `gladiators-back.png` — гладиаторы со спины.

Что в скелете (`caesar.json`):
- кости `root → body → chest → neck → head → face → jaw / browL / browR / lidL / lidR`, `head → wreath`, `chest → armL / armR`;
- сетки с весами: `torso` (низ — body, грудь — chest: дыхание, тряска), `cheek` и `mouthIn` (верх — голова, низ — челюсть: рот открывается, кожа тянется без щелей);
- `face` двигается чуть сильнее головы, `wreath` — в обратную сторону: объём при покачивании (псевдо-3D, как у тигра из примеров);
- анимации `idle` (дыхание, моргание), `laugh` (4 «ха», событие `ha` — звук), `zap` (злые брови, распахнутые глаза, событие `zap` — удар);
- `bolt.json` — молния: последовательность из 6 кадров, additive, анимация `strike`; код ставит её от глаза к песку.
- `glads.json` — гладиаторы: `idle`, `flinch`.

Как пересобрать: `node ../cut.mjs <лист> <папка>` — вырезка с зелёного; `build-atlas.mjs` — атлас (мягкие стыки, щёки, кадры молнии);
`build-skeleton.mjs` — скелеты (координаты частей — в пикселях листов). Пути к временной папке в скриптах — с машины, где собиралось.
Открыть в редакторе Spine: Import Data → `caesar.json` (картинки — `images/`).
