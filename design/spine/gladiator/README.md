# Гладиатор для Spine

Части персонажа сгенерированы нейросетью (лист `parts-sheet.png`), вырезаны и собраны скелетом в `glad.json`.

- `images/` — части в масштабе скелета: `torso` (тело с ногами и щитом), `head` (шлем), `upper` (плечо), `fore` (предплечье с мечом), `eye` (свечение глаз).
- Кости: `root` → `body` (бёдра) → `head`, `upper` → `fore`.
- Анимации: `idle` (стойка, дыхание), `clash` (замах и удар, событие `hit` — момент удара), `win` (меч вверх).

Открыть в редакторе: Spine → Import Data → `glad.json` (папка картинок — `images/`). После правок: Export → JSON + атлас,
положить в `assets/glad/` (`glad.json`, `glad-red.atlas` + `.webp`; синяя команда — тот же скелет с перекрашенным атласом `glad-blue`).
