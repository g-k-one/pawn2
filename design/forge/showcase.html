Горн · витрина эффектов

Все эффекты движка вживую, с пресетами. Тап по сцене — повторить эффект. Под каждым — строка, которой он запускается.

загружаю движок…

Как пользоваться

Ядро — один файл, пакеты эффектов подключаются после него только там, где нужны. Подробно — README в сборке (npm run forge → dist-forge).

Запустить эффект

Квадрат эффекта — 360 единиц; x, y — центр на экране, size — сторона в пикселях.

Forge.play('goldboom', { x: 200, y: 340, size: 360 });

Пресет и привязка к элементу

Имя:пресет — готовый набор цветов и настроек. el — эффект следует за элементом и обрезается по нему.

Forge.play('hitsigil:arcane', { el: card });
Forge.play('shield:frost', { el: avatar, loop: true });

Эффект с картинкой

img — адрес или <img>. Настоящую картинку на время эффекта прячут: эффект рисует её сам.

const h = Forge.play('shatter', { el: prize, img: gift.src });
// замереть на последнем кадре: { hold: true }, потом h.stop()

Подключить

Пакеты — после ядра, в этом порядке.

<script src="forge/forge.js"></script>
<script src="forge/forge-hits.js"></script>
<script src="forge/forge-matter.js"></script>

Свой эффект

k — инструменты ядра: частицы, спрайты, ленты, формы, объёмные предметы.

Forge.define('pulse', k => ({ atlas: 'aura', period: 1,
  init(s){}, update(s, dt){},
  render(s, c){ const t = s.cycle;
    k.sprite(c, 180, 180, 120 + 200 * t, 0, 1 - t, 1,
      c.at.map['sglow:W0'], 1, [1, .6, .2]); } }));

Управление

Ручка эффекта и общие настройки.

h.stop(); h.alive(); h.set('hitAt', 1.2);
Forge.list();       // [{ name, presets, img, period }]
Forge.lite = true;  // экономный режим
Forge.destroy();    // отдать видеопамять
