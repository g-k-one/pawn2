# Цезарь на Rive — заставка старта арены

Сцена собирается из текста, без редактора Rive:
`gen.mjs` пишет `scene.rml` (Rive Markup Language) → `rive . --once` (Rive CLI) → `build/caesar.riv` → копия в `assets/caesar/caesar.riv`.

```bash
node gen.mjs
rive . --verify
rive . --once
rive . --screenshot=f.png --advance=113   # кадр 113 (удар молнии)
```

- Картинки — `img/` (части Цезаря и гладиаторы — из нейросети, см. `design/spine/caesar` и `design/spine/ART-RULES.md`; фон — небо и стены колизея).
- Цезарь — группы (Node) с поворотами и масштабом; рот и щёки «тянутся» растяжением по вертикали вслед за челюстью.
- Молнии, свечение глаз, кольцо удара, вспышка — вектор Rive: обводки с пером (мягким краем), прорисовка обрезкой контура (TrimPath), режим screen.
- Тайминг (60 fps): подъём 0–44, «ха» на 30/48/66/84/140/158, замах 102–111, удар 111, конец 180. Те же кадры — в `src/app/16d-caesar.js` (звук, вибрация).
- `.riv` можно открыть в редакторе Rive: `rive . --rev` (нужен вход в аккаунт) или через `rive push`.
- Для продакшна Rive требует платный план (Cadet) для экспорта в продукт; локальная сборка `--once` — без водяного знака.
