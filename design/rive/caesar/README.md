# Цезарь на Rive — заставка старта арены

Сцена собирается из текста, без редактора Rive: `prep.mjs` → `gen.mjs` → `scene.rml` → `rive . --once` → `build/caesar.riv` → копия в `assets/caesar/caesar.riv`.

```bash
node prep.mjs        # фон, гладиаторы, кадры молнии и удара (src/*.png из Magnific → img/)
node gen.mjs         # персонаж и хореография → scene.rml (части персонажа берёт из ../lab/img, сетки — ../lab/meshes.json)
rive . --verify
rive . --once
rive . --screenshot=f.png --advance=114   # кадр удара
```

## Как устроен персонаж

Приёмы взяты из разбора примеров Rive Marketplace (`../refs/NOTES.md`):

- **Части из Magnific** одного масштаба: лысая основа головы, шапка волос, венок двумя половинами (`../lab/src/headparts.png`); брови, веки, глаза-смех и рты без кусков кожи вокруг (`../lab/src/face2.png`); руки — четыре целые позы (`../lab/src/arms2.png`); туника.
- **Сетки по контуру** (`../tools/meshgen.mjs`): точки по силуэту и внутри, триангуляция Делоне — как у Wukong и Snake, а не решётка.
- **Волосы** — 7 цепочек костей по прядям, **венок** — 2 цепочки; качаются волной с запаздыванием.
- **Глаза в масках-глазницах**: белок, радужка со зрачком (вектор) следит за целью `Look`, веко из Magnific ездит внутри маски (моргание, прищур на замахе).
- **Мимика — смена рисунка**: рот (ухмылка / улыбка / «ха» / рёв), глаза-дуги на смехе, злые брови на замахе; подбородок опускается сеткой на кости челюсти; голова сжимается и тянется на каждом «ха»; лицо сдвигается за взглядом с параллаксом.
- **Руки — смена поз** (висит / кулак / «стоп» / вверх), срез плеча спрятан под рукав туники (нахлёст), в проёме рукава — кожа плеча. Смена позы — в момент быстрого движения: замах, подмена, проскок, сжатие.
- **Дыхание**: туника на позвоночнике, грудь поднимается.
- **Молнии из глаз** — 8 нарисованных кадров (Solo, режим сложения света), удар о песок — 8 кадров, плюс заранее рассчитанные искры по баллистике, электрические дуги и волна; вспышка экрана и тряска; гладиаторы вздрагивают (сетка на 3 кости).

Тайминг (60 к/с): подъём 0–38, «ха» на 50/66/82/142/158, замах 98–111, удар 112, конец 180. Те же кадры — в `src/app/16d-caesar.js` (звук, вибрация). Машина состояний — `SM`, анимация — `Intro`.

Отрисовка — около 0,4 мс на кадр (`rive . --bench=300`), файл ~1,1 МБ.
