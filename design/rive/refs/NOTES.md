# Разбор примеров Rive Marketplace

Файлы — `refs/*.riv`, разбор — `node ../tools/riv-dump.mjs <файл> [--tree] [--json out.json]`
(свой декодер .riv: схема типов и свойств — `tools/rive-schema.json`, выгружена из `rive schema --json`).

## Выводы для Цезаря

1. Части — растр из Magnific, но **сетка по контуру формы** (20–60 точек), рёбра — вдоль сгиба; веса — на 2–3 кости.
2. **Глаза в маске** (контур глазницы): веко едет внутри, зрачок — за целью (TranslationConstraint), моргание — сдвиг века.
3. **Волосы, венок, плащ** — цепочки костей с запаздыванием (вторичное движение).
4. Персонаж — **отдельный артборд**, в сцену вставляется NestedArtboard; эмоции — отдельные анимации, смешиваются машиной состояний.
5. Объём без 3D — слои градиентов в масках и параллакс через ограничения с разной силой.
