Твой тикет

Концепты Magnific — для вдохновения по стилю (тексты на картинках сгенерированы, их не берём):
Как пробовать. Тяни белую ручку по цветному кольцу — тикет бежит по рангам, на стыке рангов щелчок. Точно — веди пальцем вверх/вниз по цифре. Тап по цвету — случайный тикет этого ранга, кубик — любой. Тап по любому «+» выбирает место, «Войти» садит туда (можно и сразу тапнуть место дважды). Боты садятся сами, банк растёт, последние 5 с — красный таймер.
